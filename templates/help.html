🚀 Quick Start

  1. Clone the repoDownload OwnAI to your machine.
  2. Run setupOn Linux/macOS: bash setup.sh  ·  On Windows: double-click setup.bat
  3. Start the apppython app.py then open http://localhost:5000
  4. Build your first AIClick Build AI in the sidebar, pick a type and follow the wizard.
💡 Tip: First-time setup installs all Python dependencies automatically. A GPU isn't required — everything runs on CPU too (training will be slower).

Manual install

git clone https://github.com/HRnewcoll/ownai.git
cd ownai
python -m venv venv
source venv/bin/activate    # Windows: venv\Scripts\activate
pip install -r requirements.txt
python app.py

📋 Requirements

  • Python 3.10+ — check with python --version
  • 8 GB RAM minimum; 16 GB+ recommended for 7B+ parameter models
  • NVIDIA GPU + CUDA (optional but strongly recommended for training speed)
  • ~10 GB disk space for base model downloads
⚠️ Large models: Models like Llama-3 8B or Mistral 7B require at least 16 GB RAM (or 8 GB VRAM + 4-bit quantization). Smaller models like Phi-2 run fine on 8 GB RAM.

🐳 Docker Install

Docker is the easiest way to deploy OwnAI on any server.

# Build and start (CPU mode)
docker compose up -d

# View logs
docker compose logs -f

# Stop
docker compose down

Models and datasets are stored in ./models_dir and ./uploads on the host, so they persist across restarts.

💡 GPU with Docker: Install nvidia-container-toolkit on the host, then uncomment the GPU section in docker-compose.yml.

🔨 1 · Build Your AI

The Build AI wizard guides you through five steps:

  1. Choose AI Type — Search or browse 28 types across 6 categories. Use the custom type and describe your niche in plain English — OwnAI will auto-select the right training template.
  2. Pick Base Model — Select a pre-trained model to fine-tune. Smaller models (Phi-2, DistilBERT) train faster; larger ones produce better results.
  3. Set Capabilities — Enable web search, voice, reasoning, multimodal, or PC control.
  4. Configure Training — LoRA (fast, low memory) or full fine-tuning. Set epochs, batch size and learning rate.
  5. Review & Create — Confirm settings and click Create AI.

📂 2 · Add Datasets

Go to Datasets in the sidebar to add training data. Three sources are supported:

  • File Upload — .txt, .csv, .jsonl, .json, images, PDFs
  • HuggingFace Hub — Search and link any of the 100,000+ public datasets (e.g. tatsu-lab/alpaca)
  • Web Scrape — Enter URLs; OwnAI will fetch and extract text for training
💡 Format tip: JSONL files work best. Each line should be {"text": "your training example"}.

⚡ 3 · Train

From My Models, click Train next to your model. Then click Start Training.

  • Training runs in the background — live logs stream to the page in real time.
  • The generated training script is visible via the View Script button — you can copy and run it on any machine.
  • Status updates automatically: draft → training → ready (or failed).
  • Training can be stopped at any time.
⚠️ First run: The first epoch will take longer as HuggingFace downloads the base model weights (~1–30 GB depending on model size).

💬 4 · Run & Chat

Once status is ready, click Run. The interface adapts to your AI type:

  • Text / Chat models — Chat interface with optional voice input
  • Vision models — Image upload + analysis
  • Audio / Speech models — Audio file upload
  • Data / Trading models — Guided prediction inputs
  • Agentic models — Additional tool panel (web search, file access, commands)

You can also use Quick Prompts from the sidebar to send common requests instantly.

📦 5 · Export Model

Download your trained model weights and configuration as a zip file from the Train page using the Download Model button.

The zip contains:

  • train.py — the generated training script
  • ownai_config.json — your model configuration
  • training.log — full training log
  • Model checkpoint files (once training is complete)

You can load the exported checkpoint on any machine using the standard HuggingFace API.

❓ FAQ

Do I need a GPU?

No — CPU-only training works for all model types, but it's much slower. A mid-range NVIDIA GPU (8 GB VRAM) makes training practical. For large models (7B+) use 4-bit quantization (QLoRA).

How do I use a gated model like Llama or Gemma?

Accept the model's license on HuggingFace, then set HUGGINGFACE_HUB_TOKEN=hf_... in your .env file.

Can I train on custom image / audio data?

Yes — upload image or audio files via the Datasets page. They'll be used by the vision / audio training scripts automatically.

Where are my models saved?

In the models_dir/ folder inside the project directory. Each model gets its own subfolder containing the checkpoint, config and training script.

How do I run OwnAI on a server / in the cloud?

Use Docker Compose. Set PORT, SECRET_KEY, and optionally a reverse-proxy like nginx for HTTPS. See the Docker Install section above.

My training says "failed" — what do I do?

Check the training log for error messages. Common causes: missing dependencies (run pip install -r requirements.txt again), out-of-memory (reduce batch size or use QLoRA), or a missing dataset.
