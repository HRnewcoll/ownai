ℹ️ How Scoring Works

Each problem is solved using the Think-Act-Observe-Verify agentic loop:

  1. Think – plan approach
  2. Act – write code + tests (TDD)
  3. Observe – run in sandbox
  4. Verify – check tests pass; loop if not

A problem is PASS only when all assertions succeed. Partial marks are not given.

Target scores

  • HumanEval-lite: ≥ 70%
  • Reasoning: ≥ 60%
  • Code Fix: ≥ 65%
